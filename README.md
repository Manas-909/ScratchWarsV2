# Scratch Wars
<img width="347" height="266" alt="image" src="https://github.com/user-attachments/assets/00e7b43a-133a-412f-a731-acd2f8312825" />

Scratch Wars is pygame based space shooter (like) game, though instead of shooting you have to dodge obstacles like asteroids and enemy ships in your way to reach the planet in front of you.

# How to play it
You need to have Python installed on your system. You can download it from official python website
then you can clone this repository with ```git clone https://github.com/Manas-909/ScratchWarsV2```
then go to ScratchWarsV2 with ```cd ScratchWarsV2``` and install pygame with ```python -m pip install pygame```
and finally run the game with ```python scratchwars.py``` or you can download the windows executable from [itch.io](https://neongs505.itch.io/scratch-wars)
